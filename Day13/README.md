# FizzBuzz Game

## About the Project

FizzBuzz is a simple Python programming exercise that prints numbers from **1 to 100** according to specific rules.

This project was created as part of my Python learning journey to practice **loops, conditional statements, comparison operators, and the modulo operator (`%`)**.

## How the Game Works

The program checks every number from 1 to 100:

* If the number is divisible by **3 and 5**, it prints `FizzBuzz`.
* If the number is divisible by **3**, it prints `Fizz`.
* If the number is divisible by **5**, it prints `Buzz`.
* Otherwise, it prints the number itself.
