# Day 14 - Higher Lower Game

## Python Learning Journey

On Day 14, I built a **Higher Lower Game** using Python.

In this project, the player compares two famous Pakistani people and guesses who has more followers.

For this version of the project, I used **Pakistani actors, singers, cricketers, and other famous Pakistani people** instead of international celebrities.

---

## Project

### Higher Lower Game

The game shows two Pakistani famous people:

- **A**
- **B**

The player has to guess which person has more followers by typing:

- `A`
- `B`

If the answer is correct, the score increases and the game continues.

If the answer is wrong, the game ends.
