# Day 09 - Blind Auction

## About the Project

This is my **Day 09 project** from my Python Learning Journey.

Today, I built a **Blind Auction** program using Python. The program allows multiple people to place bids without seeing each other's bids. At the end, the program finds and displays the person with the highest bid.

- Using `for` loops
- Using `while` loops

- Handling user input
- Improving problem-solving skills

## How the Program Works

1. The program welcomes the users to the secret auction.
2. Each bidder enters their name.
3. Each bidder enters their bid amount.
4. The bid is stored in a dictionary.
5. The program asks if there are any other bidders.
6. The process continues until there are no more bidders.
7. The program compares all the bids.
8. The bidder with the highest bid is declared the winner.

## Key Features

- Multiple bidders can participate.
- Each bidder enters a private bid.
- Bids are stored using a dictionary.
- The highest bid is automatically calculated.
- The winner and winning bid are displayed.
- The program continues until all bidders have finished.
