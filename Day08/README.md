# Day 08 - Caesar Cipher

## About the Project

This is my **Day 08 project** from my Python Learning Journey.

Today, I built a **Caesar Cipher** program using Python. The program allows the user to encrypt a message by shifting each letter by a specific number of positions in the alphabet. It can also decrypt the message back to its original form.

- Building a program with reusable logic

## How the Program Works

1. The user chooses whether to **encode** or **decode** a message.
2. The user enters the message.
3. The user provides a shift number.
4. For encoding, each letter is shifted forward in the alphabet.
5. For decoding, each letter is shifted backward.
6. Spaces, numbers, and special characters remain unchanged.
7. The program displays the encrypted or decrypted message.
8. The user can choose to run the program again.

## Key Features

- Encode messages
- Decode messages
- Custom shift number
- Handles spaces and special characters
- Allows the user to run the program multiple times
- Interactive command-line interface
