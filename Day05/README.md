# PyPassword Generator

This is a simple Python project that generates a random password.

The program asks the user how many **letters, symbols, and numbers** they want in the password. It then randomly selects the characters and shuffles them to create a password.

## How it works

1. Enter the number of letters.
2. Enter the number of symbols.
3. Enter the number of numbers.
4. The program generates a random password.

### Example

```text
Welcome to the PyPassword Generator!
How many letters would you like in your password?
12
How many symbols would you like?
2
How many numbers would you like?
2

Here is your password: hKkC&8uK1Fu2bYG
```
