# Day 15 - Coffee Machine

## Python Learning Journey

On Day 15, I built a **Coffee Machine Project** using Python.

The program allows the user to choose a drink, insert coins, check resources, and receive the coffee and change.

---

## Project

### Coffee Machine

The coffee machine offers three drinks:

- Espresso
- Latte
- Cappuccino

The machine checks whether there are enough ingredients before making the selected drink.

It also calculates the payment and gives the correct change.

---

## Example

```text
What would you like? (espresso/latte/cappuccino): latte

Price: $2.5

Please insert coins.
How many quarters?: 12

Here is $2.42 in change.
