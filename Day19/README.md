# Day 19 — Turtle Race Game 🐢🏁

## 📌 Project Overview

In Day 19 of my Python learning journey, I created a Turtle Race Game using Python's Turtle graphics module.

In this game, multiple colorful turtles race toward the finish line. The player predicts which turtle will win before the race starts.

This project helped me practice Python concepts while creating a fun and interactive game.

## 🎯 Concepts Learned

- Python Turtle Graphics
- Creating and controlling turtle objects
- Using loops
- Working with random numbers
- Handling user input
- Using conditional statements
- Understanding the basics of interactive games

## 🛠️ Technologies Used

- Python
- Turtle Module
- Random Module

## ▶️ How to Run the Project

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the Day19 project folder in PyCharm or another Python editor.
4. Run the Python file.
5. Select your predicted winning turtle and watch the race!

I learned how to create multiple turtle objects, move them randomly, and build a simple racing game. This project improved my understanding of Python programming and helped me practice turning code into an interactive experience.
