## Projects

### Day 01 - Band Name Generator
A simple program that generates a band name using the user's city and pet name.

### Day 02 - Tip Calculator
A calculator that determines how much each person should pay after adding a tip.

### Day 03 - Treasure Island
A text-based adventure game where the player makes choices to find the treasure.

### Day 04 - Rock Paper Scissors
A game where the player competes against the computer in Rock Paper Scissors.

### Day 05 - PyPassword Generator
A random password generator using letters, numbers, and symbols.

### Day 06 - Karel the Robot
Programming challenges using functions and loops in Reeborg's World.

### Day 07 - Hangman
A word-guessing game where the player tries to guess a hidden word.

### Day 08 - Caesar Cipher
A program that encrypts and decrypts messages using the Caesar Cipher technique.

### Day 09 - Blind Auction
A program that collects secret bids and determines the bidder with the highest bid.

### Day 10 - Calculator
A calculator that performs mathematical operations and allows continued calculations.

### Day 11 - Blackjack
A command-line Blackjack game where the player competes against the computer.

### Day 12 - Number Guessing Game
A number guessing game where the player tries to guess a randomly generated number. This project helped me practice scope, global and local variables, constants, loops, and conditional statements.

### Day 13 - FizzBuzz
A program that checks numbers from 1 to 100 and prints "Fizz", "Buzz", or "FizzBuzz" depending on whether the number is divisible by 3, 5, or both. I also practiced debugging and fixing errors in Python.

### Day 14 - Higher Lower Game
A game where the player compares two famous people, brands, or entities and guesses which one has more followers. This project helped me practice dictionaries, functions, loops, conditions, and game logic.

### Day 15 - Coffee Machine
A command-line coffee machine program that allows users to choose drinks, check resources, insert coins, calculate change, and make coffee.

### Day 16 - Coffee Machine using OOP
Rebuilt the Coffee Machine project using Object-Oriented Programming. The project uses classes, objects, attributes, methods, and separate Python modules to organize the coffee machine, menu, and money system.
