## Final Project - Karel the Robot

For the Day 06 final project, I used Karel the Robot to solve a maze/hurdle challenge.

The goal was to make the robot navigate through the maze and reach the finish point.

I used the **right-hand rule**, where the robot checks whether the right side is clear and moves accordingly.

## Concepts Used

### Functions

I created a `turn_right()` function using three `turn_left()` commands.

### While Loop

I used a `while` loop to keep the robot moving until it reached the goal.

### Conditions

The program checks whether the right side or front is clear before deciding what action to take.
