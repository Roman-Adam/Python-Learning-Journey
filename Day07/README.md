# Day 07 - Hangman Game

## About the Project

This is my **Day 07 project** from my Python Learning Journey.

Today, I built a classic **Hangman Game** using Python. The player has to guess the hidden word one letter at a time before running out of attempts.

- Handling user input

## How the Game Works

1. The program chooses a random word.
2. The hidden word is displayed as blanks.
3. The player guesses one letter at a time.
4. If the guessed letter is correct, it is revealed.
5. If the guessed letter is incorrect, the player loses an attempt.
6. The hangman drawing progresses with incorrect guesses.
7. The player wins when the complete word is guessed.
8. The player loses when all attempts are used.

## Key Features

- Random word selection
- Letter guessing system
- Tracks guessed letters
- Displays the progress of the hidden word
- Limited attempts
- Win and lose conditions
- Interactive command-line gameplay
