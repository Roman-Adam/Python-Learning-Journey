# Day 18 - Turtle Graphics & Randomness

Day 18 of my Python Learning Journey.

In Day 18, I practiced Python Turtle Graphics, loops, random colors, random directions, and functions by creating different visual projects.

## Projects

### 1. Random Walk

In this project, I used Turtle to create a random walking pattern.

The turtle moves forward and randomly changes its direction. I also used random RGB colors to make the path colorful.

**Topics Practiced:**
- Turtle Graphics
- Loops
- Random module
- Functions
- RGB colors
- Random directions

---

### 2. Spirograph

In this project, I created a colorful Spirograph using Turtle.

The turtle repeatedly draws circles and changes its heading by a small angle to create the circular pattern.

**Topics Practiced:**
- Turtle Graphics
- Loops
- Functions
- Random colors
- Angles
- `circle()`
- `setheading()`

---

### 3. Hirst Painting

For the final project, I created a Hirst-style dot painting using Python Turtle.

This project was inspired by the colorful spot paintings of British artist Damien Hirst.

I used rows of colorful dots to recreate this style of artwork with Python.

**Topics Practiced:**
- Turtle Graphics
- Loops
- Random colors
- RGB colors
- Functions
- `dot()`
- `penup()`
- Working with colors
