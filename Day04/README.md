## Project: Rock Paper Scissors

I built a simple Rock Paper Scissors game in Python.

The player chooses:

- `0` → Rock
- `1` → Paper
- `2` → Scissors

The computer makes a random choice, and the program compares both choices to determine whether the player wins, loses, or draws.
