# 🐢 Turtle Crossing Game

## 📌 Project Overview

The Turtle Crossing Game is a simple game developed using Python's Turtle graphics module.

In this game, the player controls a turtle and tries to cross a busy road while avoiding moving cars. The difficulty increases as the player progresses through the levels.

This project is part of my **100 Days of Code: The Complete Python Pro Bootcamp by Dr. Angela Yu**.

## 🎮 How to Play

- Use the **Up Arrow key** to move the turtle forward.
- Avoid the moving cars on the road.
- Reach the other side safely to complete a level.
- Each successful crossing increases the level and difficulty.
- Avoid colliding with cars!
