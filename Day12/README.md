# Day 12 - Number Guessing Game

## Project: Number Guessing Game

In Day 12, I learned how to use **functions, loops, conditionals, randomisation, and variables** to build a Number Guessing Game in Python.

The program randomly selects a number between 1 and 100. The player chooses a difficulty level and gets a limited number of attempts to guess the correct number.

## Topics Learned

* Functions
* While Loops
* Conditional Statements
* Randomisation
* Variables
* User Input
* Comparison Operators
* `random.randint()`

## Project Features

* Generates a random number between 1 and 100.
* Two difficulty levels:

  * Easy: 10 attempts
  * Hard: 5 attempts
* Gives hints when the guess is too high or too low.
* Counts the remaining attempts.
* Shows the correct answer when the player wins or runs out of attempts.

## Project File

`number_guessing_game.py`

## How to Run

1. Make sure Python is installed.
2. Open the project in PyCharm or VS Code.
3. Run `number_guessing_game.py`.
4. Choose `easy` or `hard`.
5. Start guessing the number.

## What I Practiced

This project helped me practice using loops and conditional statements together to create a complete interactive Python game.
