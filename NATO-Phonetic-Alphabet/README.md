# Day 26 – NATO Phonetic Alphabet Project 🐍

## 📌 Project Overview

This is my Day 26 project from the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu.

The NATO Phonetic Alphabet project converts each letter of a user's input word into its corresponding NATO phonetic code.

For example:

**Input:**
```text
ROMAN
```

**Output:**
```python
['Romeo', 'Oscar', 'Mike', 'Alfa', 'November']
```

## 🛠️ Technologies & Concepts Used

- Python
- Pandas Library
- CSV File Handling
- Dictionary Comprehension
- List Comprehension
- Loops and Conditional Statements

## ⚙️ How It Works

1. Reads the NATO phonetic alphabet data from a CSV file.
2. Creates a dictionary using dictionary comprehension.
3. Takes a word from the user.
4. Converts each letter into its corresponding NATO phonetic code using list comprehension.
5. Displays the final result.

## ▶️ How to Run

**1. Install Pandas:**

```bash
pip install pandas
```

**2. Run the Python file:**

```bash
python main.py
```

**3. Enter any word** and see its phonetic representation!
