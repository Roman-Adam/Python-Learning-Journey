# Day 10 - Calculator

## About the Project

This is my **Day 10 project** from my Python Learning Journey.

Today, I built a **Calculator** using Python. The calculator can perform basic mathematical operations such as addition, subtraction, multiplication, and division.

The program also allows the user to continue calculating with the previous answer or start a new calculation.

- Using dictionaries
- Storing functions in a dictionary
- Using `for` loops
- Using `while` loops
- Using conditional statements
- Recursion
- Handling user input
- Improving problem-solving skills

## How the Program Works

1. The user enters the first number.
2. The program displays the available mathematical operations.
3. The user chooses an operation.
4. The user enters the next number.
5. The program performs the selected calculation.
6. The result is displayed.
7. The user can continue calculating with the previous result.
8. The user can also start a new calculation.

## Key Features
